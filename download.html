v1.3.0 Windows 10 / 11 · x64 约 98 MB（不含听力音频） 只装给当前用户（免管理员） 含智慧悬浮窗 1.1.0

这一版把两个小工具也装进来了：装完桌面多一条「智慧悬浮窗」快捷方式 （resources\bin\smart_dock.exe），不想装也能从下面单独拿。

听力音频不在安装包里（36MB 的 mp3 会把安装包顶过网盘 100MB 的单文件上限）， 要离线听听力，装完这个再装下面的「音频包」。

适用于 Windows 的 JinSuper 智控班级 · 免安装

smart_dock.exe（智慧悬浮窗 1.1.0：当前科目 / 下节课 / 北京时间， 按钮「随机抽选 / 作业 / 笔 / 设置」，可收成小侧边栏、可开机自启、可置顶）· 随机抽选.exe（一个窗口抽人）· 随机抽选.html（网页版，双击即开）。 三个都不写注册表（除了悬浮窗那个「开机自启」开关是你自己点的）。
单拿悬浮窗时：「随机抽选 / 作业」会先找装好的「811 套装」并用它的离线副本开页； 没有套装就直接开同目录的 随机抽选.html，最后才退到网址。

C++ 静态编译 不需要 .NET / VC++ 运行时 合计不到 1 MB
123 云盘 蓝奏云盘 密码 1234

懒得装？网页版直接开

  • 随机抽选一页一个按钮，双击也能用
  • 随机抽选 · 完整版1–6 人、不重复、签筒
  • 今日作业勾选、留言、截图

三个 exe 都是 MinGW-w64 编译的 C++ 静态链接程序：-static + -static-libgcc + -static-libstdc++，除了 Windows 自带的 DLL 以外 不依赖任何运行库，拷到别的机器上双击就能跑。
安装包的「离线副本」就是 resources\site：学校连不上站点时，桌面版直接读它； 听力音频由上面那个扩展包装进同一个目录。
源码在仓库的 dock/（build.cmd 一条命令重新编译）， 课程表与名单是编译期从站点数据生成的 —— 课表换了就重新编译一次。
